# VÆRIN — 3D scroll watch website

Pages: index.html · collection.html · craftsmanship.html · maison.html · contact.html · product.html?w=aurelis|noctis|vantage

Stack: HTML, CSS, vanilla JS, GSAP + ScrollTrigger, Three.js r128, smooth-scrollbar 8.8.4, Font Awesome 6.4.2, Google Fonts (all via CDN).

Open with a local server for best results (e.g. `python3 -m http.server`) — needs internet for the CDN libraries.

Edit products in js/data.js. Prices, address, email, phone, warranty text and the contact forms are PLACEHOLDERS / demo only.
